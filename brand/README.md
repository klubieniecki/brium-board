# Brium Board — brand assets

## Logo

`brium-logo.png` is the logo. The badge outline is the **real board profile** —
the same 610 × 360 cut line the stencil draws, at 12 px weight.

| File | Use |
| --- | --- |
| `brium-logo.png` | primary — README header, listings, print |
| `brium-logo-square.png` | same logo on a square canvas — avatars, thumbnails |
| `brium-logo-transparent.png` | background knocked out |

The logo is **raster**. That's fine for GitHub, MakerWorld and Printables, but
if you ever need it large-format or laser-engraved you'll want it as vector —
the badge outline below is already vector, so it's only the type and the
scribble that would need redrawing.

The type and the scribble are black, so **the transparent version needs a light
background**. On dark it disappears. Use the light background version, or
recolour before you put it on anything dark.

## Board outline

The bare cut-line shape, black stroke, no fill. This is what the badge in the
logo is built from.

| File | Weight |
| --- | --- |
| `brium-board-outline-3px.svg` | hairline |
| `brium-board-outline-5px.svg` | light |
| `brium-board-outline-8px.svg` | medium |
| `brium-board-outline-10px.svg` | heavy |
| `brium-board-outline-12px.svg` | heaviest — the weight used in the logo |

Coordinates are **1 unit = 1 mm**, so the SVG is natively 610 × 360 and
dimensionally accurate. Generated by `outline.py` — add any weight you want to
the tuple and re-run.

Note the stroke straddles the path, so at 12 px the drawn shape reads ~6 px
larger on every side than the true cut line. Don't trace one of these at 1:1;
that's what the stencil is for.
